# אילה פרקש – הדגמה לעיצוב אתר חדש

גרסת הדגמה לעיצוב מחודש של האתר ayalafarkash.co.il, עם התכנים של האתר הקיים.

## מה יש בפנים
- `index.html` – עמוד אחד שמכיל את כל האתר: ראשי, מי אני, אימון רגשי, חרדות וטראומות (EMP), זוגיות רעילה, שאלון עצמי, מדריך, בתקשורת, מאמרים, שאלות ותשובות, צור קשר
- `styles.css` – העיצוב (עברית מימין לשמאל, מותאם לנייד)
- `app.js` – אינטראקציות: שאלון עצמי, וידאו שנטען רק בלחיצה, טופס שפותח וטסאפ, תפריט נגישות
- `assets/img` – תמונות מהאתר המקורי, מכווצות ל-WebP

## טכנולוגיות
HTML/CSS/JS עכשוויים בלי ספריות: אנימציות שמגיבות לגלילה (scroll-driven animations), Popover API, View Transitions,
אקורדיון details שנפתח בתנועה רכה, `color-mix`, אפקט זכוכית (backdrop-filter), נתוני Schema.org לגוגל, ותמיכה ב-prefers-reduced-motion.

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח את http://localhost:8000

> הערה: טפסי ההרשמה הם להדגמה בלבד (עוד לא מחוברים למערכת דיוור). טופס "צור קשר" פותח הודעת וטסאפ מוכנה.
